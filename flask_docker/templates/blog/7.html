Part 3: Creating a Database with SQLAlchemy

So this will be the harder of the tutorials as we will have to go back and add stuff to both our python file and our docker compose file. The reason we want to do this is because it solves one of the biggest problems (in my opinion) with static websites, which is that JavaScript is only capable of storing data locally within the browser, meaning once you refresh the page or move to a new one, anything JavaScript was doing is reset. However, with the help of a SQL database we can store data in our backend and use it across as many pages as we want for all users to see ! For example, we can make a guestbook that we control on our own hardware, without having to use a third party provider like SmartGB or Atabook (No shade to people use them, but I think self-hosting is awesome sauce ^-^).

With all that being said, let's not waste any time and get straight to adding our database !

To start with let's set up our PostgreSQL service and an optional Adminer service in our docker compose file. Go ahead and follow along with the code in the box below.

# This is our app image, if you followed along with the previous tutorial about virtualizing our site, you can go ahead and skip most of these lines aside from the two additional lines at the end (environment & depends_on).

services:

     web:

          build: .

          container_name: flask_app

          ports:

               - "5000:5000"

          environment: # This will allow our image to connect to the SQL database.

               - SQLALCHEMY_DATABASE_URI=postgresql://user:pass@db:5432/db_name

               # Make sure to replace user, pass, & db_name with the info we will provide in the postgres image.

          depends_on: # This prevents our site from running if the database isn't already up and running.

               - db

# Now we can set up our database using the official PostgreSQL docker image! Make sure it's all properly tabbed in.

     db:

          image: postgres:13 # Version 13 of the official postgres image

          container_name: postgres_db

          environment: # Here we can set up our username, password, & database name for our app image above.

               POSTGRES_USER: user

               POSTGRES_PASSWORD: pass

               POSTGRES_DB: db_name

          ports:

               - "5432:5432"

          volumes: # This will mount the database's data in a volume for easy access/portability

               - postgres_data:/var/lib/postgresql/data

# This next container is completely optional but it is nice as it adds a GUI for our database for easy management.

     adminer:

          image: adminer

          ports: # This is the localhost port where we will access our database's GUI

               - "8080:8080"

# This next part won't be a container but it will set up the volume that we specified in the postgres section

     volumes:

          postgres_data:

The hard part is over :D !!.

Now all we have to do is add some stuff to our requirements.txt file and our app.py file. Let's start with our app file. Follow along with the box please ^-^

#!/usr/bin/env python3

from flask import Flask, render_template

# The following two import statements will add Migrate for portability and Flask's version of SQALchemy

from flask_migrate import Migrate

from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)

# Add these two config statements above the secret key. These will connect our app to our database and disable debug notifications.

app.config[ 'SQLALCHEMY_DATABASE_URI'] = "postgresql://user:pass@db:5432/db_name"

app.config[ 'SQLALCHEMY_TRACK_MODIFICATIONS'] = False

app.config[ 'SECRET_KEY'] = "bunnies r the bestest animalz ever !!11!!!!!!"

# These two lines will set our database and migrate variables for use in the rest of the file.

app = SQLAlchemy(app)

app = Migrate(app, db)

@app .route('/')

def index():

     return render_template('index.html')

if __name__ == '__main__': # Make sure the line below is tabbed in !

          with app.app_context(): # Make sure the lines ar-- nvm, u should know how python's syntax works by now

               db.create_all() # This will create the database within our site

     app.run(host="0.0.0.0", port=5000)
