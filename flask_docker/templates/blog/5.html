Part 1: The Basics

Alright, so here's my tutorial on how to set up a basic web app with Flask. This is all based on my knowledge (obviously) so don't expect anything too crazy technical or in-depth, but I'll still try my best to get things across

So to start with we have to set up the directory for our project. It's actually pretty simple and all we really need to start with is a shrimple structure like this:

| - Flask_App

| ------ static

| --- css

| - style.css

| --- js

| - script.js

| ------ templates

| - index.html

| ------ app.py

Now that we have our directory set up with our starter files we can get to work on building our app!

To start off, we're going to open app.py in our text editor of choice and copy the following lines into it.

# This is called a shebang, it tells the os where the binary to execute this script it!

#!/usr/bin/env python3

# This line imports the 4 functions we will need from the flask module Flask is obviously how we will be building our site and render_template is used to serve our html files to our clients' browsers. later on we can import functions like request or redirect to handle forms or redirect to other pages from our python code.

from flask import Flask, render_template

app = Flask(__name__)
