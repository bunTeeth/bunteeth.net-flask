Welcome to a simple overview of my homelab! I'm still in the beginning of my homelabbing journey, and my lab is pretty small and inefficient due to how expensive the hardware for this stuff is but it's very fun regardless and I plan to continuously upgrade it with new stuff. :D

My NAS:

My current NAS is a UGREEN NASync DH4300 Plus with 8TB of storage space that I've limited to about 3.6TB of usable space via RAID 1 for redundency, which is a budget NAS for beginners like myself. It may be a budget NAS with a lot of limitations but it works for my current needs of file backup and hosting a few Docker containers with the following services.

My Nas

My services:

Media Center:

Gluetun - Routes containers through VPN

qBittorrent - Downloads stuff totally legally

Prowlarr - Torrent/Usenet indexer manager

Flaresolverr - Cloudflare captcha solver

Sonarr - Searches Prowlarr indexers for TV Shows

Radarr - Searches Prowlarr indexers for Movies

Jellyfin - Media server (no transcoding due to hardware limitations)

Cloudflare Tunnels:

Cloudflared - Docker container for running a Cloudflare tunnel to this device for remote access

Python http server & NGINX - The old, static version of my website

Other:

Pi-hole - Network wide adblock & DNS server
