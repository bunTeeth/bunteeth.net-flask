Part 1: The Basics

Alright, so here's my tutorial on how to set up a basic web app with Flask. This is all based on my knowledge (obviously) so don't expect anything too crazy technical or in-depth, but I'll still try my best to get things across

So to start with we have to install python, python comes pre-installed on Linux, but for Windows and MacOS we have to install it from either their official website. Then we'll need a code editor like Visual Studio Code or PyCharm. Then we have to set up the directory for our project. It's actually pretty simple and all we really need to start with is a shrimple structure like this:

| - Flask_App

| ------ static

| --- css

| - style.css

| --- js

| - script.js

| ------ templates

| - index.html

| ------ app.py

| ------ requirements.txt

Alternatively, you can download this sample directory of empty files to follow along with this tutorial series here.

Now that we have our directory set up with our starter files we can get to work on building our app!

To start off, we're going to open app.py in our text editor of choice and type the following lines into it.

# This is called a shebang, it tells the os where the binary to execute this script is!

#!/usr/bin/env python3

# This line imports the 2 functions we will need from the flask package that we'll need 2 to start with. Flask is obviously how we will be building our site and render_template is used to serve our html files to our clients' browsers. later on we can import functions like request or redirect to handle forms or redirect to other pages from our python code.

from flask import Flask, render_template

# Here we can set a variable we can use for initializing our app.

app = Flask(__name__)

# This line will set our app's secret key. Though I personlly have not encountered a need for this yet, It's still a best practice to add this for security, so make sure it's super duper secret.

app.config[ 'SECRET_KEY'] = "bunnies r the bestest animalz ever !!11!!!!!!"

# Now we can start defining what will happen when someone browses to different areas of our site like /index or /about

# Make sure you tab in this line as well.

app.run(host="0.0.0.0", port=5000) # This lets the app run on our computer's main network interface instead of just our loopback (localhost) interface. This is important if we plan on hosting our site.

It's as shrimple as that! We now have the backbone of our web app, but don't run it juuuusssst yet because we told our app to serve index.html but right meow that's just an empty file :c

So let's fix that! Let's now open it in our text editor of choice and add the following code to it:

Finally, we need to install Flask, we can technically do this by just running the command pip install flask, but since we're gonna be virtualizing our website with Docker in my next tutorial, we should write a file to our project folder named requirements.txt that will list any packages our app will need. It's actually super duper simple because all we need to do is list the names of the packages we need to install.

flask

Look at all that empty space XD

Awesome sauce !!! Now we should have a functioning web app that serves us a static html page. To finish off this part of the tutorial we need to install flask by running pip install -r requirements.txt in our terminal and then we can run our app with either python3 app.py in the terminal (Command Prompt on Windows and Terminal on Mac) and navigate to http://localhost:5000 to access our site. If we did everything correctly we should see a blank white page with our header text at the top.
