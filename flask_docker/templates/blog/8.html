Part 4: Creating & Querying Database Tables

Hiii! Welcome to part 4 of my tutorial series on building a website with Flask. In this article I'll go over creating SQL tables with SQLAlchemy and how we can query them.

If you've followed along with the last three parts you should now have a working flask website that runs inside a Docker container alongside a PostgreSQL database that we have linked to our site via SQLAlchemy. With SQLAlchemy, we can easily manage the contents of our database with python through our app.py file.

The first thing we're going to do is create a simple HTML file that serves a page with a blog post form. This form will send an HTTP POST request to the /create-blog-post route in our app to add the title of our post. We don't need to specify a date as it will default to the current time, although if you want to go back afterwords and add that function, you can! Anyways, let's get started with the form, which you can add to the index.html file we made earlier, or make a new file (make sure it's in the templates folder as well, though).

Awesome! Now comes the long part. We need to create the database table for blog posts, then create the /create-blog-post route that we mentioned in the blog post form. This will involve writing a python class that creates the table and defines its parts, then we have to add the route functionality to add the post to the table and redirect us to the post. We also need to create a route that can display our blog posts depending on one of the post's database columns, which will be title for this example. With that being said, let's get to work on updating our app.py file. Please follow along with the box and add any new lines.

#!/usr/bin/env python3

from flask import Flask, render_template, redirect, request # We need to add redirect to send the user to different routes & request to handle the info we send in via our HTML form

from flask_migrate import Migrate

from flask_sqlalchemy import SQLAlchemy

import psycopg

# We need to import datetime so that we can timestamp our blog posts

from datetime import datetime

app = Flask(__name__)

app.config[ 'SQLALCHEMY_DATABASE_URI'] = "postgresql://user:pass@db:5432/db_name"

app.config[ 'SQLALCHEMY_TRACK_MODIFICATIONS'] = False

app.config[ 'SECRET_KEY'] = "bunnies r the bestest animalz ever !!11!!!!!!"

db = SQLAlchemy(app)

migrate = Migrate(app, db)

# This is where we'll define our database tables.

# To create a table we have to make a class for it that takes in the SQLAlchemy model class. This class will represent our table and it's structure

class BlogPost(db.Model):

     __tablename__ = 'blog_posts' # This is only used in the database and we won't need it to interact with the table from within our app

     id = db.Column(db.Integer, primary_key=True) # This will be how we identify data in our table and is necessary in each table we add.

     title = db.Column(db.String, unique=True, nullable=False) # This lets us give our posts a title that must be unique and can't be empty

     date_posted = db.Column(db.DateTime, default=datetime.now()) # This sets the date of our post to the exact time we added it to the database in our local timezone

     # Now we need to create an init function for our class that sets lets it take in its' title and date

     def __init__(self, title, date_posted):

          self.title = title

          self.date_posted = date_posted

# This function creates a string for each object, we won't use it but it's nice to have

     def __repr__(self):

          return f'Title: {self.title} Date: {self.date_posted}'

# App Routes

@app.route('/')

def index():

     return render_template('index.html')

@app.route('/blog/<int:id>') # This route displays the requested blog post filtered by it's id

def get_post(id):

     post = db.session.get(BlogPost, id) # These two lines will grab the post and serve it

     return render_template(f'{post.id}.html')

@app.route('/create-blog-post', methods=['POST']) # This creates the route and lets it take in a POST request, which is what we specified our form to send

def add_post():

     title = request.form.get("title")

     date_posted = datetime.now()

     if title != "": # This if statement will make sure that it only redirects us to the post if we successfully added it.

          post = BlogPost(title=title, date_posted=date_posted)

          db.session.add(post)

          db.session.commit()

          return redirect(f'/blog/{post.id}')

     else:

          return redirect('/')

if __name__ == '__main__':

     with app.app_context():

          db.create_all()

     app.run(host="0.0.0.0", port=5000)
