Part 4: Creating & Querying Database Tables

Hiii! Welcome to part 4 of my tutorial series on building a website with Flask. In this article I'll go over creating SQL tables with SQLAlchemy and how we can query them as well as how we can display them in our HTML with the templating language, Jinja2.

If you've followed along with the last three parts you should now have a working flask website that runs inside a Docker container alongside a PostgreSQL database that we have linked to our site via SQLAlchemy. With SQLAlchemy, we can easily manage the contents of our database with python through our app.py file.
